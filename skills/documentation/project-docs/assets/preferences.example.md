# project-docs preferences

Copy this file to `~/.config/agent-skills/project-docs/preferences.md` and keep only the lines you want fixed. The skill reads it before it asks: an answer written here is not asked again. Delete a line to be asked again.

- Contributing: issues and pull requests are welcome.
- Language when the repository has no README: English.
- Repository owner's name: keep it where the repository already shows it; never add it to new prose.
- GitHub Pages: offer it for public repositories.
- Decisions: record at most five; list the others as "Not recorded yet".

Turning on GitHub Pages, committing and pushing still need your yes each time: this file never answers those.
