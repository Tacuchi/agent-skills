# herdr-coordination 2.0.0

Coordinates agents in Herdr through authorized panes, the current help, verification of the visible model and effort, and following states, questions and restarts. An accepted prompt does not prove receipt or result; permissions and reserved effects need a written answer from the person and a check afterwards.

Version 2.0.0 publishes the skill in English. Its `description` changes, and so does the text a host matches to activate it; that is why it is a major version. The rules are the same as in 1.1.0.

Acquire only the `skills/orchestration/herdr-coordination/` directory from `Tacuchi/agent-skills` once the ref `skill/herdr-coordination/v2.0.0` exists; it works with no other harness and no other offer.
