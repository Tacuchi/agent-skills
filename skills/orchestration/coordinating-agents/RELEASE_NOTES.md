# coordinating-agents 1.4.0

Coordinates coding agents under any multi-agent orchestrator through its current help, verification of the effective model, effort and permission mode, and following states, questions and restarts. An accepted send does not prove receipt or result; permissions and reserved effects need a written answer from the person and a check afterwards. Reference files for Herdr, Orca, teamctl and Dorothy map each one onto the same cycle.

Version 1.4.0 keeps the coordinator's own tab whole: the agents' panes are created in another tab, in any orchestrator or agentic development environment (ADE), including ones mapped from their own help such as T3 Code. Reserved requests reach the person as a structured question when the host has that tool. The Herdr reference was measured again on `hc` 0.1.21 and `herdr-app` 0.1.15: a split pane starts in the folder of the pane that was cut, a hidden tab reports stale sizes, and `layout.resize --weight` evens out a row. The Orca reference adds the traps of stuck workers and split timeouts. Agents that share a clone are told not to use `git stash`, and an agent that died produced no result. Every 1.3.0 rule stays.
