# coordinating-agents 1.5.0

Coordinates coding agents under any multi-agent orchestrator through its current help, verification of the effective model, effort and permission mode, and following states, questions and restarts. An accepted send does not prove receipt or result; permissions and reserved effects need a written answer from the person and a check afterwards. Reference files for Herdr, Orca, Paradev, T3 Code, AgentsRoom, teamctl and Dorothy map each one onto the same cycle.

Version 1.5.0 adds adapters for Paradev, T3 Code and AgentsRoom. Paradev has tabs and panes driven by its `superset` CLI; T3 Code runs each agent as a thread; AgentsRoom gives each agent its own tab through MCP tools and asks the person to confirm every spawn. The three adapters come from the installed help and tool catalog and say that nothing was exercised. The Orca reference was measured again on macOS 1.4.258. Every 1.4.0 rule stays.
