# exploring-designs-with-agents 1.0.0

Runs visual design explorations (logos, app icons, or app screens) with several agents in parallel across converging rounds: one shared brief agreed with the person, a common `manifest.json` and CSS-variable SVG delivery contract, a zero-dependency local HTML comparator served on `127.0.0.1` where the person stars favorites, and final production-kit generation by the winning agent.

Acquire the whole `exploring-designs-with-agents` directory (including `references/` and `assets/`) from `Tacuchi/agent-skills` once the ref `skill/exploring-designs-with-agents/v1.0.0` exists. It works standalone; orchestration and design-craft skills are optional complements.
