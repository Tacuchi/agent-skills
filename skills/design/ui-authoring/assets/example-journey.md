# Fictional example: appointment lookup

| Screen | Action | State and response | Accessibility |
|---|---|---|---|
| Search | Submit date | Loading; button disabled until the response arrives | Announce "Searching for appointments" without moving focus |
| Results | No appointments | Empty message with an option to change the date | Keep focus on the results heading |
| Results | The lookup fails | Error in text with a "Retry" option | Announce the error and allow going back to the date |

The data and people are fictional. Do not copy names, screenshots or addresses of real systems when reusing it.
