# ui-authoring 3.0.0

Version 3.0.0 changes only the `description`: it now says the skill specifies an interface before it is built, and that reviewing, critiquing, polishing or implementing an existing interface belongs to an interface review or design critique skill, if available. The text a host matches to activate it changes; that is why it is a major version. The rules are the same as in 2.0.0.

Acquire the whole `ui-authoring` directory (including `references/` and `assets/`) from `Tacuchi/agent-skills` once the ref `skill/ui-authoring/v3.0.0` exists. It needs no other skill and no particular CLI. It asks for an approved destination; without one it delivers the draft in the conversation.
