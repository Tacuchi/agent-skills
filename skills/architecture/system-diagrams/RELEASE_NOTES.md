# system-diagrams 2.0.0

Version 2.0.0 publishes the skill in English. Its `description` changes, and so does the text a host matches to activate it; that is why it is a major version. The rules are the same as in 1.1.0: C4 levels 1–3, Mermaid and Structurizr DSL templates, engine selection, local rendering by default and a remote view only with explicit consent. The guide is now `references/c4-and-engines.md` and the example `assets/example-flow.md`.

Acquire the whole `system-diagrams` directory (including `references/` and `assets/`) from `Tacuchi/agent-skills` once the ref `skill/system-diagrams/v2.0.0` exists. It works with no other harness and no renderer installed.
