# Critical thinking

Three tight checks to run **before you act** on a plan, decision, or conclusion. Each is cheap and catches a distinct failure mode. Grilling/gap-driven questioning interrogates *the option you picked*; this builds the *failure narrative* and the *opposing case* instead — use them together, not as substitutes.

Run the mode that fits; you rarely need all three.

## 1. Pre-mortem (before committing to a plan)

Assume it is later and the plan **failed**. Narrate why.

- "It's done and it went wrong. What broke, and what was the most likely cause?"
- List the top 2–3 failure causes; for each, the cheapest guard to add now.
- If a cause has no cheap guard and high impact, revise the plan before starting.

Inversion beats forward optimism: it surfaces risks that "will this work?" hides.

## 2. Falsification (before accepting a conclusion)

A conclusion that only fits *your* explanation is untested.

- List the **competing explanations** that fit the same evidence.
- For the leading one, name the observation that would **disprove** it — then look for that, not for more confirming evidence.
- Grade the evidence: direct vs circumstantial, verified vs assumed. Do not upgrade an assumption to a fact by repeating it.

If you can't state what would change your mind, you don't yet have a conclusion.

## 3. Dialectic steelman (on a contested decision)

Before defending a choice, build the other side honestly.

- **Thesis:** the chosen position, stated fairly.
- **Antithesis:** the *strongest* opposing case — the version its best advocate would make, not a strawman.
- **Synthesis:** what survives from both. Often the answer moves; sometimes it hardens with a clear reason.

## Output

Keep it short (per the `technical-writing` skill, if it is available): the check you ran, what it surfaced, and the resulting change — or an explicit "no change; here's why". A pre-mortem that changes nothing and says nothing was not run honestly.
