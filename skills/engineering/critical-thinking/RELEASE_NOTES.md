# critical-thinking 1.0.0

Version 1.0.0 publishes three short checks to run before acting on a plan, decision or conclusion: a pre-mortem, falsification against competing explanations, and a dialectic steelman. It needs no other skill; the skills it mentions are optional complements.

Acquire the whole `critical-thinking` directory from `Tacuchi/agent-skills` once the ref `skill/critical-thinking/v1.0.0` exists.
