# security-practices 1.0.0

Version 1.0.0 guides the handling of secrets, PII, parametrized SQL, input validation, permissive CORS and external state mutations: it flags findings with a proposed fix, keeps database access read-only and never silences or executes a mutation on its own. It needs no other skill; the skills it mentions are optional.

Acquire the whole `security-practices` directory from `Tacuchi/agent-skills` once the ref `skill/security-practices/v1.0.0` exists.
