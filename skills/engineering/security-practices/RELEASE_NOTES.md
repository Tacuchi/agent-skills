# security-practices 1.2.0

Guides the handling of secrets, PII, parametrized SQL, input validation, permissive CORS and external state changes. It flags findings with a proposed fix and keeps agent database access read-only. Other skills are optional.

Version 1.2.0 adds a review before making a repository public. It covers deleted content in Git history, retained Actions logs, commit emails, privacy assumptions and the owner's decision about visibility and Pages. The bundled Python 3 scanner reads standard input and reports counts by type and file. An optional local context view masks detected values.

Acquire the whole `security-practices` directory once the ref `skill/security-practices/v1.2.0` exists.
