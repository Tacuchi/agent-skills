# coding-standards 1.1.0

Publishes the stack-agnostic coding standards: SOLID, fail-fast, self-documenting names, DRY with the rule of three, DTOs between layers, constructor injection, framework-first UI, the FE-BE sparse-DTO/PATCH contract, logging by severity and fitting the repository you change. It needs no other skill; the skills it mentions are optional complements.

Version 1.1.0 shortens the `description` to fit the 1024-character limit of the skills standard and adds four rules: keep process identifiers out of the code, never read a failed lookup as an empty result, make error messages name the expected shape and what arrived, and derive a repeated list from one source.

Acquire the whole `coding-standards` directory from `Tacuchi/agent-skills` once the ref `skill/coding-standards/v1.1.0` exists.
