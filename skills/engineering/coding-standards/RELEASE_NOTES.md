# coding-standards 1.0.0

Version 1.0.0 publishes the stack-agnostic coding standards: SOLID, fail-fast, self-documenting names, DRY with the rule of three, DTOs between layers, constructor injection, framework-first UI, the FE-BE sparse-DTO/PATCH contract, logging by severity and fitting the repository you change. It needs no other skill; the skills it mentions are optional complements.

Acquire the whole `coding-standards` directory from `Tacuchi/agent-skills` once the ref `skill/coding-standards/v1.0.0` exists.
