# coding-standards changelog

## [1.1.0] — 2026-11-14

- The `description` is shortened to fit the 1024-character limit of the skills standard; its meaning does not change.
- New rules: keep process identifiers (plan, task, ticket, acceptance criterion) out of code, tests and user-facing text; a failed read is not an empty result; an error message names the expected shape, the valid values and what arrived; one source for a list.

## [1.0.0] — 2026-09-29

- First public version, copied from the author's own convention coding-standards and generalized: the company house style (a mandated domain language), company table prefixes and API envelope names, and company-specific skill names were removed; mentions of other skills are optional.
