# software-testing 1.0.0

Version 1.0.0 publishes the test strategy: it asks before running any runner, requires a red-then-green regression test for every bugfix, proves a preexisting failure against an untouched base, treats low coverage as a gap, picks the unit/integration/full level and resolves the command from the repository's own wrapper and scripts. It needs no other skill; the skills it mentions are optional complements.

Acquire the whole `software-testing` directory from `Tacuchi/agent-skills` once the ref `skill/software-testing/v1.0.0` exists.
