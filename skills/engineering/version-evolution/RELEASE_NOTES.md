# version-evolution 1.0.0

Version 1.0.0 guides the selection and incremental upgrade of language, framework and toolchain versions: it separates the current baseline from the target, prefers supported GA and LTS lines, checks compatibility and deployment capacity and pins the result. The `references/` directory records Java 25 and Spring Boot 4 migration traps. It needs no other skill; the skills it mentions are optional.

Acquire the whole `version-evolution` directory from `Tacuchi/agent-skills` once the ref `skill/version-evolution/v1.0.0` exists.
