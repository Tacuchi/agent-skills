# reviewing-code 1.0.0

Version 1.0.0 publishes the diff review and task closure discipline: atomic single-intent diffs, propose-then-execute, a closure quality gate over comments, complexity, dead code and anti-patterns, branch verification before editing, and records of non-obvious decisions and new dependencies. It needs no other skill; the skills it mentions are optional complements.

Acquire the whole `reviewing-code` directory from `Tacuchi/agent-skills` once the ref `skill/reviewing-code/v1.0.0` exists.
