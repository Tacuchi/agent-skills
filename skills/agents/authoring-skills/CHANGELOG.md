# authoring-skills changelog

## [1.1.0] — 2026-11-14

- The description section states the standard's limits: `name` of at most 64 characters and equal to the folder name, `description` of at most 1024 characters, a version in `metadata.version`, and the description written as a quoted string.
- The body section adds two rules: the floor goes inline, and commands run as written.
- New gotchas: a skill is episodic, so a rule for every turn or for subagents needs a hook or the repository's instruction file; one `SKILL.md` per skill folder.
