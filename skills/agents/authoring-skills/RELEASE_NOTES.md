# authoring-skills 1.1.0

Guides writing an agent SKILL.md: a description that works as a trigger, a lean body with progressive disclosure, imperative steps the weakest model can follow and trigger validation before shipping. It needs no other skill; the skills it mentions are optional.

Version 1.1.0 adds the limits of the skills standard, the rule that what must always hold goes inline in SKILL.md, and two facts about hosts: a skill fires once and dilutes, so a rule for every turn needs the host's enforcement layer, and a nested `SKILL.md` is indexed as another skill.

Acquire the whole `authoring-skills` directory from `Tacuchi/agent-skills` once the ref `skill/authoring-skills/v1.1.0` exists.
