# creating-tools 1.0.0

Version 1.0.0 organizes auxiliary developer tools under `docs/tools/<tool>/` with a README contract, immutable timestamped runs and an `output/latest` pointer. It ships two dependency-free Node scripts, `scaffold-tool.mjs` and `record-run.mjs`, and a README template. It needs no other skill.

Acquire the whole `creating-tools` directory from `Tacuchi/agent-skills` once the ref `skill/creating-tools/v1.0.0` exists.
