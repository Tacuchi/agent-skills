# git-conventions 1.0.0

Version 1.0.0 sets safe git rules: read-only operations are always allowed, commits are proposed with exact paths and a one-line message and run only after approval, and push, amend, force, merge, rebase or reset need an explicit request. It also verifies the declared branch and dirty state before editing. It needs no other skill; the skills it mentions are optional.

Acquire the whole `git-conventions` directory from `Tacuchi/agent-skills` once the ref `skill/git-conventions/v1.0.0` exists.
