# resolving-merge-conflicts 1.0.0

Version 1.0.0 resolves a merge already in progress: it inspects base, ours and theirs, resolves paths one at a time without touching foreign work, stops on ambiguous hunks and runs the merged checkout's build and tests before proposing an approved commit. It needs no other skill; the skills it mentions are optional.

Acquire the whole `resolving-merge-conflicts` directory from `Tacuchi/agent-skills` once the ref `skill/resolving-merge-conflicts/v1.0.0` exists.
