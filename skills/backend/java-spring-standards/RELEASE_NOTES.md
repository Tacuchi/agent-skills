# java-spring-standards 1.0.0

Version 1.0.0 gives Java and Spring Boot rules for writing and reviewing backends: layered MVC with thin controllers, constructor injection, transaction discipline, sized async executors, Bean Validation, a single centralized advice that never leaks internals, parameterized Log4j2 logging and DTOs that follow the project. It needs no other skill.

Acquire the whole `java-spring-standards` directory from `Tacuchi/agent-skills` once the ref `skill/java-spring-standards/v1.0.0` exists.
