# angular-standards 1.0.0

Version 1.0.0 gives Angular and TypeScript rules for writing and reviewing frontends: a two-layer data/presentation layout, all HTTP through one shared wrapper, version-aware standalone and signal adoption, reactive forms, strict typing, centralized error handling that never silences, framework-first styling and component tests that do not mount the whole injector chain. It needs no other skill.

Acquire the whole `angular-standards` directory from `Tacuchi/agent-skills` once the ref `skill/angular-standards/v1.0.0` exists.
